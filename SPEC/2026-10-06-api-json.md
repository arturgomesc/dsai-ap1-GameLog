# API JSON pública, somente leitura (2026-10-06)

## O quê e por quê
O catálogo só pode ser lido pelas páginas HTML. Uma API JSON pública e somente leitura permite que outros programas consultem jogos e avaliações, e mostra que o app é integrável. Reaproveita a busca existente (BUS-01..09) e as estatísticas da página do jogo (PAG-02..04).

## Critérios de aceitação
- API-01: `GET /api` devolve JSON com a versão e a lista de endpoints; todas as respostas de `/api/*` são `application/json; charset=utf-8` e trazem `Access-Control-Allow-Origin: *`
- API-02: `GET /api/jogos` lista jogos com `items`, `page`, `pages`, `total` e `per_page`; aceita os mesmos filtros da busca (`q`, `genero`, `plataforma`, `ano_de`, `ano_ate`, `nota_min`, `ordem`) e `page`; valor inválido é ignorado, nunca erro (BUS-08), e página fora do intervalo cai na última válida (BUS-04)
- API-03: `per_page` padrão 20, máximo 50, mínimo 1; valor inválido volta ao padrão
- API-04: cada item traz `slug`, `titulo`, `lancamento` (ISO), `desenvolvedora`, `generos`, `plataformas`, `capa` (URL absoluta ou caminho da capa SVG), `nota_media` (1 casa, ou `null`) e `avaliacoes` (contagem), `url` (página HTML)
- API-05: `GET /api/jogos/<slug>` traz os campos do item mais `sinopse` e `histograma` (notas de 0 a 10); jogo inexistente ou removido responde 404 em JSON `{"erro": "..."}` (CAT-07)
- API-06: `GET /api/jogos/<slug>/avaliacoes` lista avaliações visíveis, da mais recente para a mais antiga, paginadas (mesmas regras de `page` e `per_page`), com `usuario` (nome de usuário), `nota`, `texto`, `spoiler`, `editada`, `data` e `curtidas`; avaliações ocultas nunca aparecem
- API-07: nenhuma resposta traz e-mail, hash de senha, listas privadas, status ou qualquer dado de conta além do nome de usuário
- API-08: métodos diferentes de GET e HEAD respondem 405 em JSON, e rota desconhecida sob `/api/` responde 404 em JSON, nunca HTML
- API-09: respostas de leitura levam `Cache-Control: public, max-age=60`
- API-10: o número de consultas ao banco por requisição de lista não cresce com o tamanho da página (no máximo 6)

## Fora do escopo
Escrita por API, autenticação por token, limite de taxa, versionamento além de `/api`, documentação OpenAPI.
